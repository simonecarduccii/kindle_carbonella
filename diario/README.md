# Diario di sviluppo

Qui annotiamo ogni passaggio del progetto Carbonella: cosa è stato fatto, come, quanto tempo ha
richiesto, le fonti consultate, gli screenshot e le note.

- Un file per attività, con la data nel nome: `AAAA-MM-GG-titolo.md`.
- Gli screenshot e le foto vanno in `diario/img/`, con lo stesso prefisso di data.

Il riassunto di tutto il percorso, versione per versione, è in [EVOLUZIONE.md](EVOLUZIONE.md).
